# BoldFrame Animation Website

Open `index.html` in a browser to preview the site.

## Structure
- index.html — Home
- about.html — About
- services.html — Services
- portfolio.html — Portfolio with filters
- contact.html — Contact
- css/style.css — All styling
- js/script.js — Menu, portfolio filters and contact form
- images/ — Temporary SVG project placeholders

## Replace the placeholders
Replace the SVG files in `images/` with your own project images when ready.
You can also add MP4 videos and update the portfolio cards to use `<video>` elements.

## Contact
Change `hello@boldframeanimation.com` in `contact.html` and `js/script.js` to the company's real email address.
